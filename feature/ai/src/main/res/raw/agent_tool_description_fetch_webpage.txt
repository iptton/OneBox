获取指定URL的网页内容。

功能说明：
- 抓取网页并提取内容
- 支持多种提取模式：纯文本、原始HTML、链接、图片、全部
- 自动处理字符编码（支持中文等多语言）
- 支持重定向跟踪

使用场景：
- 获取网页文章内容
- 提取页面中的链接列表
- 抓取网页中的图片URL
- 获取网页的HTML源码用于分析

注意事项：
- 需要网络连接
- 部分网站可能有反爬机制
- 内容默认限制5000字符，可通过max_length参数调整
- 不支持需要登录的页面

工具边界：
- 本工具走 HTTP 直连抓取，不执行 JavaScript，拿不到 JS 动态渲染的内容
- 页面需要 JS 渲染、或要与已打开的浏览器页面交互（点链接、填表单、读取当前标签页）时，改用 browser_navigate / browser_read_page
- 只是抓静态文章内容、链接或 HTML 源码时优先用本工具，比唤起浏览器更轻量
