一次读取多个文本文件内容，适合代码 Agent 同时拉取接口、实现、调用方等关联上下文，减少多轮往返。

输入支持本地路径、file:// URI，以及可解析为真实路径的 SAF content:// URI；工具会先统一转换为 file:// URI。

每个文件项支持：
- file_uri：必填
- start_line：可选
- end_line：可选

限制：
- 只支持文本文件
- 任一文件无法读取或无法解析为本地 file:// 时，会整体返回错误

工具边界：本工具面向"多文件批量读取"，一次拉取多个文件的（可选行范围）内容。要在单个文件里搜索关键词、按行号精读片段时改用 process_file。
