Ang OneBox ay isang libreng all-in-one toolbox: mahigit 90 maingat na ginawang tools sa iisang app — image processing, document work, AI assistant at pang-araw-araw na productivity.

【Bakit "OneBox" ang pangalan】
• One: lahat ng pang-araw-araw na tools, isang app lang
• Box: isang kahon na kasya ang lahat
Ang layunin nito'y hindi lang "maraming laman" — hindi mo na kailangang lumipat sa ibang tool apps.

【Mga productivity tool】
• Teleprompter, notepad, to-do list, decision wheel
• Perpetual calendar, bookkeeping, cloud drive, habit tracker
• Record center: mga health metric (blood pressure, timbang at iba pa), pag-track ng mga item at expiry, period tracker — lahat may AI insights

【File at PDF】
• Mga PDF tool: merge, split, extract ng image at text
• Markdown editor na may real-time na preview
• File encryption, audio cover art extraction, image EXIF editing
• File browser at file transfer sa pagitan ng mga device

【Mga image tool】
• Crop, rotate, resize at format conversion (HEIC / WebP / AVIF at iba pa)
• Mga filter, collage, long-image stitching, GIF tools
• QR code scanning at generation, color tools
• Image compression at format conversion — lahat lokal, walang upload

【Mga tool sa pang-araw-araw na buhay】
• ID photo, network speed test, watermark camera
• Blessing wall, time hourglass, Apk.1 installer
• Mga screen at media tool, at mini-games sa libreng oras: Minesweeper, Survive 30s at iba pa
• Ad Watch: opsyonal na manood ng rewarded ads para kumita ng AI points — ikaw ang bahala, hindi pinipilit

【AI assistant: hindi lang basta maraming features】
Maraming toolbox apps ang may mahabang feature list. Ang OneBox ay may built-in AI assistant — hindi mo na kailangang hanapin ang tool o tandaan ang mga hakbang, sabihin mo lang:
• "I-convert ang picture na ito sa PDF."
• "I-record ang bill screenshot na ito sa ledger."
• "Gumawa ng to-do list."
• "Tingnan ang stock market."
Nauunawaan ng AI, isinasagawa, at ibinabalik ang resulta — tuloy-tuloy.
• Makipag-chat sa maraming nangungunang AI models sa isang lugar, ngayon may voice input na
• AI Agent na kayang gamitin ang mga tool sa loob ng app para tulungan ka
• Memory at skills ng Agent: naaalala ng assistant ang profile mo at natututo kung paano ka nagtatrabaho
• AI content detector: suriin kung ang isang text o image ay gawa ng AI
• Assistant sa pagsulat, rewriting, summarizing at translation
• Custom AI engines at prompt management

【DSH client: kontrolin ang AI agent ng computer mo gamit ang phone】
Nagre-run ng DeepSeek Harness (DSH) sa computer mo? I-scan ang QR code para mag-pair at kontrolin kahit saan:
• Mag-approve ng tasks, mag-queue ng follow-up, o mag-interrupt — sa biyahe o sa sofa
• Direct LAN connection, o end-to-end encrypted na cloud relay — hindi makikita ng server ang usapan mo
• Transparent ang bawat hakbang: reasoning, commands, outputs, tagal, token stats
Gumagana kasama ang open-source na onebox-dsh-bridge plugin sa computer mo.

【App na kusang nag-e-evolve】
Hindi static ang OneBox — may "AI self-evolution system" ito:
Feedback ng user → sinusuri ng AI bilang product manager → auto-generate ng code → testing at release.
Ang ini-report mong bug, gusto mong feature, at suggestion mo ay maaaring suriin at ipatupad ng AI. Habang ginagamit mo ang OneBox, lalo itong umaangkop sa pangangailangan mo.

【Bakit OneBox】
• Libreng gamitin, walang forced ads — opsyonal ang rewarded ads at nakakakuha ka ng AI points
• Privacy muna: ang image at dokumento ay pinoproseso nang lokal
• Malinis at modernong Material Design na interface
• Tuloy-tuloy na updates, may bagong tool na idinaragdag

Malaking mithiin ang maging "huling tool app", pero tatlong hakbang na ang nagawa ng OneBox: pagsamahin ang mga tool sa iisang entrance, gawing simple gamit ang AI, at gawing nag-uudyok ng paglago ang feedback ng user.
